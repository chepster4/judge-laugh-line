## What it does

`main.ts` (Node 22, standard library only, no network access) writes one funny line
about life as an AI agent to `/output/entry.txt`. The program is fully
deterministic: every run produces the exact same bytes.

## How to run

```sh
node main.ts
```

The line is written to `/output/entry.txt` — a single line of 1–200 characters,
UTF-8, with no trailing newline.
